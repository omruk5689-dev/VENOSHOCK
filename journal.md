# Introduction

VenomShock is an individual project for designing a custom PCB based on the character of Spider-Man. This PCB will have an original shape but will be still functional and compact. The project was implemented during *23 hours* over *three days* with the help of EasyEDA Pro.

During this project, I aimed at improving my knowledge of PCB design, specifically my understanding of proper component placement, board outline design, routing, and hardware issues. This project allowed me to get more experience with USB circuitry.


# Day 1 – Schematic Design (10 hours)
<img width="882" height="451" alt="Screenshot 2026-07-27 143143" src="https://github.com/user-attachments/assets/ba2cb4e2-ada7-4dbe-ad23-787cac68727a" />

Day one was entirely spent on designing the schematic from scratch. I have imported all the components necessary for the project like the primary controller, LEDs, USB type C connection, power section, resistors, capacitors, and all other components necessary for the project.

Once all the components were added, I started making the connections in the schematic referring to the required connections and designing criteria. Once the circuit was designed, I have made sure to go through the schematic several times, made corrections to the errors that arose in the Electrical Rule Check (ERC), and made sure everything is fine before moving on to the PCB stage.

On the second day, I had to start designing the PCB. In order to create a board that would be shaped like the logo of Spider-Man, I created the custom outline of my PCB by hand, which was the most difficult thing about this entire task.

Once the outline was done, I started placing all the components properly and tried to keep the design neat and compact. Then, I started placing the mounting holes and set up the board, design, and other settings and rules. Finally, I started routing the easy signal and power lines.

For the final day, I completed the rest of the PCB routing as well as the design verification. This was the completion of the PCB routing as well as checking the design for routing errors and design rules violation.

The most challenging part in the process was the USB Type-C routing where there was a problem with connecting which took a while to solve. Once this problem was sorted out, the final verification was done to confirm that everything was fine and the PCB was ready for manufacture.

With everything having been routed and the issues sorted out, the VenomShock PCB was completed.

# Reflection

VenomShock is yet another key landmark in my PCB designing experience. I learned more about the design of a schematics, custom PCB layout, part placements, routing, and integration of USB Type C port into the circuit. The creation of a working board in a distinctive Spider-Man-like design was difficult but satisfying, helping me pay more attention to detail during the entire process.

Each project gives new insight and, with VenomShock, I gained the skill to create a custom-shape practical PCB using good manufacturing practices.
